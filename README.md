\# 🐟 基于 STM32 的观赏鱼养殖水体监测与控制系统



> 基于 STM32F103C8T6 + ESP8266 的观赏鱼养殖水体监测与控制系统  

> 实现水温、浊度实时监测，并根据水体状态对水泵进行控制，同时通过 Wi-Fi Web 页面实现远程监测与控制。



\---



\## 📌 项目简介



本项目是一套基于 \*\*STM32F103C8T6\*\* 的观赏鱼养殖水体监测与控制系统。



系统通过传感器实时采集养殖水体环境数据，并通过 OLED 进行本地显示。同时使用 ESP8266 建立 Wi-Fi 网络通信和 Web Server，使用户可以通过浏览器查看系统运行状态，并对水泵进行控制。



系统目前主要实现以下功能：



\- 🌡️ DS18B20 水温检测

\- 💧 浊度传感器检测

\- 🖥️ OLED 实时数据显示

\- 🚰 水泵控制

\- 📡 ESP8266 Wi-Fi 通信

\- 🌐 Web 网页监测

\- 🎮 水泵手动控制

\- 🤖 水泵自动控制

\- 🔄 手动 / 自动模式切换

\# 🔧 硬件组成



\## 1. STM32F103C8T6



STM32F103C8T6 作为系统核心控制器，主要负责：



\- 传感器数据采集

\- 数据处理

\- OLED 显示

\- 水泵控制

\- USART 串口通信

\- 自动控制逻辑



\---



\## 2. DS18B20 温度传感器



DS18B20 用于检测养殖水体温度。



传感器采用单总线通信方式，STM32 通过数据线与 DS18B20 进行通信并读取温度数据。



主要功能：



```text

DS18B20

&#x20;  ↓

温度数据

&#x20;  ↓

STM32

&#x20;  ↓

OLED显示

&#x20;  ↓

ESP8266

```



\---



\## 3. 浊度传感器



浊度传感器输出模拟信号，STM32 通过 ADC 对传感器输出信号进行采样。



基本流程：



```text

浊度传感器

&#x20;    │

&#x20;    │ 模拟电压

&#x20;    ▼

STM32 ADC

&#x20;    │

&#x20;    ▼

ADC采样值

&#x20;    │

&#x20;    ├──────► OLED显示

&#x20;    │

&#x20;    └──────► ESP8266

```



根据当前实验结果：



```text

ADC值越小

&#x20;   ↓

水体越浑浊

```



当前系统采用的浊度判断阈值为：



```text

1500

```



即：



```text

Turbidity < 1500

&#x20;       ↓

判断为浑浊程度较高

```



> 注：当前浊度阈值属于实验阶段设定值，实际使用时需要根据具体传感器和养殖环境进行标定。

\## 4. OLED 显示模块



OLED 用于本地显示系统运行状态。



当前显示：

可以在不打开电脑网页的情况下直接查看系统状态。

\## 5. 水泵



系统使用 5V 小型水泵进行水体循环。



STM32 不直接驱动水泵，而是通过 MOSFET 模块进行控制。



控制关系：



```text

STM32 PA8

&#x20;   │

&#x20;   ▼

MOSFET模块

&#x20;   │

&#x20;   ▼

5V水泵

```

\## 6. ESP8266 / ESP-01S



ESP8266 用于实现系统的 Wi-Fi 网络通信。



STM32 负责传感器数据采集和主要控制逻辑，ESP8266 负责：



\- Wi-Fi 连接

\- 接收 STM32 数据

\- Web Server

\- Web 页面显示

\- 接收网页控制命令

\- 向 STM32 发送控制指令



系统通信关系：



```text

STM32

&#x20; │

&#x20; │ USART1

&#x20; ▼

ESP8266

&#x20; │

&#x20; │ Wi-Fi

&#x20; ▼

浏览器

```

\# 🔌 主要接口



\## STM32 USART1



STM32 与 ESP8266 使用 USART1 进行串口通信。



```text

PA9  → USART1\_TX

PA10 → USART1\_RX

```



串口参数：



```text

波特率：115200

数据位：8

停止位：1

校验位：无

流控制：无

```



\---



\## ESP-01S 接线



```text

ESP-01S       STM32



TX            PA10

RX            PA9

GND           GND

VCC           3.3V

EN/CH\_PD      3.3V

```



> 注意：ESP8266 芯片工作电压为 3.3V，使用 ESP-01S 时需要保证供电稳定。

\# 📡 STM32 与 ESP8266 通信协议



STM32 周期性向 ESP8266 发送当前系统数据。



数据格式：



```text

T=26.5,TU=1200,P=1,M=1

```



参数说明：



| 参数 | 含义 |

|---|---|

| `T` | 温度 |

| `TU` | 浊度 ADC 值 |

| `P` | 水泵状态 |

| `M` | 工作模式 |



水泵状态：



```text

P=0 → 水泵关闭

P=1 → 水泵开启

```



工作模式：



```text

M=0 → 手动模式

M=1 → 自动模式

```



\---



\# 🚰 水泵控制



\## 手动模式



当：



```text

M = 0

```



系统进入手动模式。



此时用户可以通过 ESP8266 Web 页面控制水泵。



开启水泵：



```text

Web页面

&#x20;  ↓

ESP8266

&#x20;  ↓

发送 P=1

&#x20;  ↓

STM32

&#x20;  ↓

Pump\_ON()

&#x20;  ↓

MOSFET

&#x20;  ↓

水泵开启

```



关闭水泵：



```text

Web页面

&#x20;  ↓

ESP8266

&#x20;  ↓

发送 P=0

&#x20;  ↓

STM32

&#x20;  ↓

Pump\_OFF()

&#x20;  ↓

MOSFET

&#x20;  ↓

水泵关闭

```



\---



\# 🤖 自动模式



当：



```text

M = 1

```



系统进入自动模式。



当前自动控制逻辑：



```text

温度 > 30℃

&#x20;      OR

浊度 < 1500

&#x20;      ↓

&#x20;   水泵开启

```



否则：



```text

温度 ≤ 30℃

&#x20;      AND

浊度 ≥ 1500

&#x20;      ↓

&#x20;   水泵关闭

```



对应 STM32 控制程序：



```c

if (Mode == 1)

{

&#x20;   if (Temp > 30 || Turbidity < 1500)

&#x20;   {

&#x20;       Pump\_ON();

&#x20;   }

&#x20;   else

&#x20;   {

&#x20;       Pump\_OFF();

&#x20;   }

}

```



在自动模式下，水泵由 STM32 根据检测数据自动控制。

\# 🧠 手动 / 自动双模式



系统设计了两种工作模式。



\## 手动模式



```text

M = 0

```



特点：



\- 用户可以通过 Web 页面控制水泵

\- STM32 不执行自动水泵控制逻辑

\- Web 页面可以开启 / 关闭水泵

```text

```



特点：



\- 水泵由 STM32 自动控制

\- 根据温度和浊度判断是否开启水泵

\- Web 页面可以查看系统状态

\- Web 页面不直接控制水泵

\# ⚠️ 注意事项



1\. ESP8266 使用 \*\*3.3V\*\* 供电。

2\. ESP8266 需要稳定的 3.3V 电源。

3\. 水泵工作电流较大时，不建议直接使用 STM32 开发板供电。

4\. STM32 通过 MOSFET 模块控制水泵。

5\. STM32 与 ESP8266 通信时需要共地。

6\. ESP8266 与 STM32 的 TX/RX 需要交叉连接。

7\. 浊度阈值 `1500` 为当前实验阶段设置的参数。

8\. 温度阈值 `30℃` 为当前自动控制实验参数，实际应用时需要根据观赏鱼种类和养殖环境进行调整。

\# 📋 项目总结



本项目以 STM32F103C8T6 为核心控制器，通过 DS18B20 和浊度传感器实现养殖水体环境数据采集，并利用 OLED 对数据进行本地显示。



在执行控制方面，通过 MOSFET 模块控制 5V 水泵，实现水体循环控制，并设计手动和自动两种工作模式。



在网络通信方面，通过 ESP8266 与 STM32 进行 USART 串口通信，将采集到的温度、浊度以及水泵状态发送至 ESP8266，再通过 Wi-Fi 和 Web Server 实现网页端实时监测。
